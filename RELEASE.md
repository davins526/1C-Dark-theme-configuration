# Критерии готовности 1.0

Статус: разработка. Версия 0.1 — прототип; текущая ветка — следующая тестовая версия.

- [ ] Тёмная и светлая темы: читаемый текст, границы, неактивные команды, выделение.
- [ ] Шрифты модулей и интерфейса с проверкой метрик, курсора и восстановления.
- [ ] Собственные значки с масштабированием и всеми состояниями команд.
- [ ] Фон только в поддерживаемых областях, без стыков при прокрутке.
- [x] Сохранение профиля и чтение при запуске; автоматические тесты.
- [x] ON/OFF, повторное применение и подтверждение палитры; автоматические тесты.
- [ ] Перечень поддерживаемых платформ, обнаружение установок и открытых сеансов.
- [ ] Тесты редакторов, конструкторов, отладки, диалогов, DPI и нескольких окон.
- [ ] Длительная работа на тестовой базе; отсутствие подтверждённых регрессий.
- [ ] Сравнение с изученным проектом и проверка лицензий всех активов.
- [ ] Воспроизводимая сборка, упаковка, инструкция и журнал изменений.

Штатная возможность 1С предпочтительна там, где она доступна. Универсальный
визуальный фильтр не заменяет проверку читаемости и корректности редакторов.
До покрытия критериев выпускаются только предварительные версии.
