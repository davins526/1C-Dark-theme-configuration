# Проверки Dark1C

## Проверка безопасности: текущий статус

После обнаружения Defender локальный запуск приложения и подключение к 1С
приостановлены. Перечисленные ниже функциональные результаты относятся к прежним
экспериментальным сборкам и не подтверждают безопасность нового бинарника.

2 ноября 2026 (время Екатеринбурга): сборка исходников `fda4f22` на свежем
Windows Server 2022 в GitHub завершилась. EXE/DLL не исполнялись. Проверка Defender
остановилась на проверке исключений: такой результат не считается отсутствием
угроз. Следующие правки усиливают подготовку одноразового сервера и диагностику;
итог отдельного сканирования нужно читать в JSON-отчёте конкретного запуска.

14 сценариев логики проверки проходят на обычных текстовых фикстурах: в том числе
отказ при выключенной защите, исключениях, ошибках, обнаружении у исходного файла,
карантине и изменении содержимого. Это тесты проверяющего кода с подставными
ответами Defender, а не сканирование Dark1C.

Скрипты сборки/CI проверены парсером Windows PowerShell 5.1. Локальная политика
исполнения не менялась. [Процесс проверки и ограничения](docs/DEFENDER.md).

## Пройдено

1. Оптимизированная сборка собственной DLL с Zig 0.14.1 и MinHook 1.3.4.
2. Сборка лаунчера и управляющего приложения с .NET Framework C#.
3. Межпроцессная загрузка DLL в собственный одноразовый тестовый процесс.
4. Рисование через установленный cairo.dll из 1С 8.5.1.1529:
   - белый фон FFFFFF -> 1E1E1E;
   - чёрный элемент 000000 -> DADADA;
   - яркий голубой акцент 19B3E6 остаётся 19B3E6;
   - картинка меняет фоновый пиксель (при тестовом затемнении 35%: 242424);
   - OFF возвращает исходные FFFFFF / 000000 / 19B3E6;
   - дочерний процесс нормально завершается.
5. Создание отдельной пустой файловой базы командой CREATEINFOBASE: код возврата 0.
6. Отдельный настоящий DESIGNER: статус Ready=1, Enabled=1, Hooks=9, Error=0.
7. Визуальная проверка дерева, панелей, контекстного меню и модуля приложения.
8. Ввод и сохранение небольшого тестового модуля в собственной тестовой базе.
9. OFF в настоящем DESIGNER: статус Enabled=0; визуально вернулись светлые фон, дерево и панели.
10. Включение через кнопку графического лаунчера, подтверждение от DLL.

## Не проверено / не заявляется

- Часы и дни непрерывной эксплуатации, нагрузка большого проекта, сложные формы.
- Все конструкторы, запросы, отладка, точки останова, много мониторов и разные DPI.
- Полное покрытие каждого окна и идеальная читаемость всех значков/состояний.
- Семантическое определение только редактора модулей для картинки.
- Другие версии платформы, 1С 8.3.27 и x86.
- Совместимость с другими инжекторами, расширениями и программами перехвата.
- Независимый аудит, цифровая подпись и пригодность для рабочей базы.

Открытые рабочие Конфигураторы не использовались для инъекции.
