# Набор значков Dark1C

Собственные векторные исходники 24 × 24: new, open, save, search, undo, redo,
run, stop, settings, code, filter, add. Варианты dark/light, единая сетка и толщина
линий. SVG масштабируются без увеличения старых растров. Код и графика набора — MIT.

Генератор: `./make-icons.ps1`. Обзор: [preview.svg](preview.svg).

Статус: дизайн набора. Автоматическая подмена значков внутри 1С ещё не включена.
Для неё нужно установить соответствие исходных ресурсов командам и проверить
неактивные/выбранные состояния. Подмена «похожих» картинок без идентификации
команды не допускается: неверный значок способен вводить пользователя в заблуждение.
