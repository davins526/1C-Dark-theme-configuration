# Описание репозитория

## About

Dark1C — экспериментальная тёмная тема для Конфигуратора 1С: графитовый интерфейс, свой фон и переключение оформления. Windows x64 · 1С 8.5.1.1529.

## Темы

1c, dark-theme, windows, configurator, cairo, csharp, minhook

## Обложка

`images/cover.jpg` — оригинальная иллюстрация для README, созданная встроенной
генерацией изображений. Не является скриншотом приложения.

Промпт: широкая графитовая обложка Dark1C, тёмные геометрические слои,
сдержанный янтарный акцент, абстрактная панель кода, надписи «Dark1C» и
«A darker workspace.», без официальных логотипов 1С и без имитации реального скриншота.
