# Dark1C 0.2.3-preview

Предварительная версия для **Конфигуратора 1С 8.5.1.1529 x64 на Windows**.
Нужен .NET Framework 4.x. Критерии стабильного 1.0 ещё не выполнены.

## Изменения

- Исправлена потеря читаемости текста выделения на синем фоне при непрозрачном
  GDI-рисовании. Исходно приглушённые пары и прозрачные надписи сохраняют прежнюю обработку.
- Устранены светлые полосы в заливке частичных рамок Win32 `DrawEdge`.
  Нулевая толщина больше не создаёт лишнюю полосу; геометрия и обрезка сохраняются.
- Включены отдельные автоматические проверки: 4096 цветовых пар и 4611 пиксельных
  сценариев рамок. Исправления проверены на собственных изображениях и контекстах GDI.
- Предпросмотр поддерживает обе палитры и установленные шрифты; настройки
  сохраняются в XML-профиле. Выбор шрифта пока меняет только образец.

## Проверка и установка

Архив публикуется только после успешной сборки и сканирования Defender в GitHub
Actions. Он содержит `Dark1C.exe` со встроенными DLL и нейтральным фоном,
лицензии, `build.json`, `defender.json`, `SHA256SUMS.txt` и `PROVENANCE.txt`.
В `PROVENANCE.txt` указаны точный коммит и запуск проверки.

Распакуйте архив, откройте отдельную тестовую базу в Конфигураторе, запустите
`Dark1C.exe`, выберите нужный PID и примените тему. Кнопка «Выключить» возвращает
исходное рисование. Перед обновлением закройте сеансы, к которым подключалась
предыдущая версия: её DLL остаётся в процессе до завершения 1С.

## Ограничения

- Новые исправления ещё не прошли визуальную проверку в настоящем Конфигураторе.
  Покрытие Cairo, прозрачных надписей, диалогов и конструкторов частичное.
- Полная матрица DPI, длительная работа и другие версии 1С не проверены.
- Замена шрифтов и значков в самом Конфигураторе не реализована; фон может
  появляться в других крупных областях, кроме редактора модулей.
- Приложение и DLL не исполняются в проверяющем CI. Сканирование относится
  только к байтам этой сборки и не подтверждает работу всех элементов 1С.
- У прежней локальной сборки 0.2.2 было обнаружение Wacatac; заключения Microsoft
  о ложном срабатывании нет. Если защита блокирует эту сборку, не отключайте её
  и не добавляйте исключения ради запуска.

Пользовательские базы, данные и обои в архив не включены.
