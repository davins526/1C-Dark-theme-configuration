# Dark1C: экспериментальная проверяемая сборка

Поддерживается только **1С 8.5.1.1529 x64**, режим Конфигуратора на Windows.
Нужен .NET Framework 4.x. Это кандидат для проверки на отдельной тестовой базе,
не стабильный выпуск для рабочей базы.

В архиве — `Dark1C.exe`, лицензии, отчёты проверки, `SHA256SUMS.txt` и
`PROVENANCE.txt` со ссылками на исходники и запуск GitHub Actions. DLL и
нейтральный фон встроены в EXE. Личных обоев, установщика и шрифтов в архиве нет.

Сборка публикуется только после успешного сканирования её файлов Defender в CI.
Программа не запускалась этим workflow; такая проверка не подтверждает работу
новых правок в 1С или отсутствие обнаружений на другом компьютере.
У прежней локальной сборки 0.2.2 было обнаружение Wacatac. Microsoft не признала
его ложным. Если защита блокирует этот кандидат, сохраните название обнаружения
и хеш из отчёта для разбора; не отключайте защиту и не добавляйте исключения.

Для проверки распакуйте архив в отдельную папку и откройте `Dark1C.exe`.
Выберите отдельный тестовый Конфигуратор, тему и нажмите «Включить».
«Выключить» возвращает исходное рисование; DLL остаётся загруженной до закрытия
подключённого Конфигуратора. Для смены версии Dark1C нужно сначала закрыть такой
сеанс. Файлы установленной платформы не заменяются.

Программа намеренно загружает DLL в выбранный процесс и перехватывает рисование.
Покрытие интерфейса частичное. Настройка шрифтов пока действует только в образце;
подмена значков и скругление всех панелей 1С ещё не реализованы.
